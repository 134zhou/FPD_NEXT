# 压力泊松求解器：从离散 MAC 网格到 2D FFT + z 向三对角

> ⚠️ **本文档与 `src/Poisson.cpp` 共同定义同一个离散算子 `div∘grad`。**
> 改任一侧必须同步更新另一侧，并重跑 `./build/fpd_check --check-poisson`。
> **Phase 7-B 起，`src/include/Wall.h` 与本文档 §14 共同定义壁面的速度边界条件
> 与噪声处理** —— 改 `Wall.h` 必须同步 §14 并重跑 `./build/fpd_check --check-wall`。
> **Phase 6 起，`src/include/Potential.h` 的 `wall_*` 与本文档 §15 共同定义壁面的
> 【粒子-壁面排斥力】** —— 那一侧管粒子，§14 那一侧管流场，两者不可混为一谈。
> 本文档的数值全部来自实测，不是推导值。

本文推导**投影法（fractional-step / projection method）里压力泊松方程的解算器**，
从交错网格的离散形式出发。连续 NS 方程本身见 `README.md`，这里不重复。

**z 边界只有一种**：x/y 周期，z 上下无滑移硬壁。求解路径相应地只有一条：

- **xy 向批量 2D FFT + 每个 `(kx,ky)` 模式在 z 向解一个 `Nz×Nz` 三对角（Thomas）**。

> ⚠️ 曾有的第二条路径（全周期 3D FFT，除以精确离散本征值
> `2(cos θx + cos θy + cos θz − 3)`）已随 z 周期边界在 **Phase 8-A 删除**。
> 推导仍留在 §4，作为「离散本征值」这个概念的记录 —— 它解释了为什么 §5 的
> 三对角对角元是 `λ_xy − 1` 或 `λ_xy − 2`（`λ_xy` 正是 xy 两个方向的那部分本征值），
> 但**不再对应任何代码**。

核心结论只有一句话：**泊松算子必须恰好等于「修正步用的梯度」与「散度检验用的散度」
的复合 `div∘grad`**。Neumann 边界不是假设出来的，而是从「壁面法向面不修正」这个
事实直接导出的——这样 `∇·v^{n+1}=0` 才在两个壁面层上也精确成立。

## 1. 记号与 MAC 交错网格布局

格距 `dx ≡ 1`，索引 `IDX(i,j,k) = i + j·Nx + k·Nx·Ny`，**x 变化最快**。

| 量 | 位置 | 数组下标 ↦ 物理坐标 |
|---|---|---|
| 压力 `p` | 体心 cell center | `(i, j, k)` |
| `vx[ijk]` | x 面 x-face | `(i+½, j, k)` |
| `vy[ijk]` | y 面 y-face | `(i, j+½, k)` |
| `vz[ijk]` | z 面 z-face | `(i, j, k+½)` |

流体域 `z ∈ [−½, Nz−½]`，高度 `H = Nz`。

**壁面情形**：壁面在 `z = −½` 与 `z = Nz−½`。对应 z 面下标
`k = −1`（虚拟，在数组之外）与 `k = Nz−1`（**在数组里，但钉死为 0**）。
自由 `vz` 自由度是 `k = 0 … Nz−2`，共 `Nz−1` 个。

> 为什么下壁是「虚拟的 −1」而上壁是「数组里的 Nz−1」：`IDX` 只对 `k ∈ [0, Nz)`
> 有定义，下壁面在 z-面下标 −1，干脆不分配；上壁面在 Nz−1，落在数组内、值恒 0。
> 这带来一个必须记住的不对称：**写 `vz` 时上壁面的那个元素存在但永远不写**。

## 2. 分数步法与「离散兼容性」要求

投影法三步（每个时间步）：

```
v*        = vⁿ + dt·( −∇·Π + f )        (1)  显式步，无压力
∇²p       = (1/dt)·∇·v*                (2)  泊松
v^{n+1}   = v* − dt·∇p                  (3)  修正步（投影）
```

第 (3) 步要保证 `∇·v^{n+1} = 0`。把它和 (2) 联立：

```
∇·v^{n+1} = ∇·v* − dt·(∇·∇p) = ∇·v* − dt·(∇²p) = 0  ⟺  ∇²p = ∇·v*/dt
```

关键在于：**第 (2) 步里的 `∇²` 必须是「第 (3) 步修正用的 `∇`」与「散度检验用的 `∇·`」
的复合 `div∘grad`**，而且三处用的是**同一套离散**。如果 `∇²` 随手取一个「看起来是
拉普拉斯」的格式（例如连续谱 `−k²` 的离散），而 `∇` 用的是面心差分，那么
`∇·v^{n+1}` 只到截断误差而非机器精度——投影法的全部意义就没了。

本项目用 z 向三对角（§5）而不是连续谱 `−k²`，正是这个要求。历史上周期版用的是
精确离散本征值 `0.5/(cos kx + cos ky + cos kz − 3)`（§4），也是同一个要求。

## 3. 离散 div 与 grad，以及 `div = −gradᵀ`

体心 `(i,j,k)` 上的散度（面心值差分到体心）：

```
(div v)_{ijk} = (vx[i,j,k] − vx[i−1,j,k])
              + (vy[i,j,k] − vy[i,j−1,k])
              + (vz[i,j,k] − vz[i,j,k−1])
```

面心上的梯度（体心值差分到面心）：

```
(grad p)_x[i,j,k] = p[i+1,j,k] − p[i,j,k]      （y、z 同理）
```

两者互为**负转置**：把 `grad` 的第 x 项 `p[i+1]−p[i]` 与 `div` 的第 x 项
`vx[i]−vx[i−1]` 对比，`div = −gradᵀ`（相差一个指标平移）。因此

```
L := div∘grad   是对称、半负定  （自伴，本征值 ≤ 0）
```

对称性在 §8 用来论证三对角矩阵对称、零空间是常向量；半负定说明 `L` 的本征值
正是 §4 里那些 `2(cos−1)` 的非正数。

## 4. （历史）周期情形的 Fourier 对角化与精确离散本征值

> ⚠️ **本节不对应任何代码**（周期路径已于 Phase 8-A 删除）。保留它是因为
> `λ_xy = 2(cos θx − 1) + 2(cos θy − 1)` 这个量仍然是 §5 的输入 ——
> z 向三对角的对角元就是 `λ_xy − 1` 或 `λ_xy − 2`。

把 `div∘grad` 逐项写出（三方向都周期回绕），对 `p = e^{i(θ_x i + θ_y j + θ_z k)}`
（`θ_x = 2πm/Nx`，等）代入：

```
(L p)/p = (e^{iθ_x} − 2 + e^{−iθ_x})
        + (e^{iθ_y} − 2 + e^{−iθ_y})
        + (e^{iθ_z} − 2 + e^{−iθ_z})
        = 2(cos θ_x + cos θ_y + cos θ_z − 3)
```

即 `L` 被离散 Fourier 基对角化，本征值 `λ(k) = 2(cos θ_x + cos θ_y + cos θ_z − 3)`。
`λ_xy := 2(cos θx − 1) + 2(cos θy − 1)` 就是它在 xy 两方向的分解，
正是 §5 里 z 向三对角的对角元所依赖的那个量。

零空间：`m=n=l=0` 时 `λ=0`，对应常向量（所有模式里唯一为零的）。周期下的定规是把
`(0,0,0)` 那个傅里叶系数清零，即 `p̄ = 0`。

> ⚠️ **壁面情形【不能】照搬这条定规**：Neumann 的零空间同样是常向量，但 `(0,0)`
> 列承载的是**水平均匀的竖直压力分布**（支撑粒子重量的静压），整列清零会把它删掉。
> 壁面用的是 §8 的 `d_0 -= 1` 定规，那是**减均值**而不是清零 —— 性质完全不同。

## 5. **壁面情形：Neumann 从「壁面法向面不修正」导出**

这是本文档最核心的一节。**不要**先写下 `∂p/∂z|_{壁面} = 0` 再去离散它——那样得到的
算子与修正步不匹配的风险很高，会破坏 `∇·v=0`。正确顺序是反过来推：

修正步 (3) 只作用在**自由**的 z 面上；两个壁面处的法向速度**永不修正**（本就是 0）：

```
vz[k] = v*_z[k] − dt·(p[k+1] − p[k])      k = 0 … Nz−2
vz[−1] = vz[Nz−1] = 0                    （壁面，恒不修正）
```

把它代进 `(div v)_{ijk} = 0`，逐层展开 z 方向那一项 `vz[k] − vz[k−1]`：

| 格胞 | `vz[k] − vz[k−1]` 中 p 的部分 |
|---|---|
| `k = 0` | `−dt·(p[1] − p[0])` |
| `k = 1 … Nz−2` | `−dt·(p[k+1] − 2 p[k] + p[k−1])` |
| `k = Nz−1` | `−dt·(p[Nz−2] − p[Nz−1])` |

于是 z 向算子的三对角结构**自动出现**，两端各「少一个 −1」：

```
次/超对角 ≡ 1
对角  d_k = λ_xy − (该层在 z 向的自由邻面数)
     = λ_xy − 1   （k = 0 或 k = Nz−1）
     = λ_xy − 2   （其余）
```

这**正是**齐次 Neumann 的标准离散（等价于 ghost `p[−1]=p[0]`、`p[Nz]=p[Nz−1]`），
但它是**导出的结论**，不是外加的假设——因此 `∇·v^{n+1}=0` 在两个壁面层上也精确成立
（下一轮的 W1 判据直接检验这一点）。这一节也解释了为什么「壁面法向速度必须在 `v*`
阶段就钉死」：兼容性（§8a）要求 `v*_z[Nz−1] = v*_z[−1] = 0`。

> `Nz ≥ 2`。`Nz=1` 时退化为 `d_0 = λ_xy`（没有 z 向邻面），公式仍成立但物理无意义。

## 6. xy 向对角化：λ_xy 与 Nx·Ny 个独立三对角组

xy 仍周期 → 2D FFT 精确对角化 xy 部分（同 §4 的 xy 项）：

```
λ_xy(m,n) = 2(cos 2πm/Nx − 1) + 2(cos 2πn/Ny − 1)     （≤ 0）
```

对每个 `(m,n)` 得到一个**独立的 `Nz×Nz` 三对角方程组**，右端是该模式的 `b̂`（复数），
系数是**实数**（λ_xy 实数）。共 `Nx·Ny` 个方程组，彼此完全独立——这是天然的并行维度。

## 7. Thomas 算法，以及「前推系数与右端无关」

三对角 `A x = b`，`a_k = c_k = 1`。前推（消元）：

```
w_0 = 1/d_0
w_k = 1/(d_k − w_{k−1})          k = 1 … Nz−1
```

`w_k` **只依赖 `λ_xy` 与 k，与右端 `b` 无关** → 因此可以 `init` 时预算一次存进
`tri_w`（`Nx·Ny·Nz` 个 double，生产盒 2 MB），每步只剩两遍 O(Nz) 扫描：

```
前代：  y_0 = b_0·w_0 ;        y_k = (b_k − y_{k−1})·w_k
回代：  x_{Nz−1} = y_{Nz−1} ;  x_k = y_k − w_k·x_{k+1}
```

复数右端：实部虚部用**同一组** `w_k`，在同一个 k 循环里同时推进（一遍扫描，不是两遍）。
**完全就地**（`y` 覆盖 `b`，`x` 覆盖 `y`）→ 零额外显存。

## 8. 奇异列 `(m,n) = (0,0)` —— 不能整列清零

历史上周期版把单点 `(0,0,0)` 清零就够了。壁面**不行**：`(0,0)` 的整个 z 列描述的是
**水平均匀的竖直压力分布**，正是支撑粒子重量的静压。整列清零 = 删掉沉降的力平衡。

该列矩阵 `A₀`（`λ_xy = 0`）是纯 Neumann 一维拉普拉斯：`A₀·𝟙 = 0`（每行元素和为 0，
见 §5 两端 d = −1、内部 −2、off-diag 1）。对称 → 零空间与左零空间都是常向量。

### 8a. 相容性

可解 ⟺ `𝟙ᵀb̂ = Σ_k b̂_k = 0`。**精确算术下自动成立**：

```
b̂_k(0,0) = Σ_{i,j} (div v*)_{ijk}
```

xy 部分在周期方向上求和为 0；z 部分沿 k 望远镜求和：

```
Σ_k (v*_z[k] − v*_z[k−1]) = v*_z[Nz−1] − v*_z[−1] = 0 − 0 = 0
```

**这正是「壁面法向速度必须在 `v*` 阶段就钉死」的理由**（§5 末）。浮点下残差
~1e-13，若不处理会积成 p 的线性漂移 → 恒定伪竖直加速度。因此**必须显式减掉均值**
并把 `|Σ_k b̂_k|` 作为诊断量输出（代码 `fix_singular_column` 的 `diag[0]`）。

### 8b. 定规的精确性（不是罚函数）

取 `A' = A₀ − e₀e₀ᵀ`（即 `d_0 −= 1`，λ_xy=0 时 `d_0: −1 → −2`），解 `A'x = b`。
左乘 `𝟙ᵀ`：

```
𝟙ᵀA'x = 𝟙ᵀA₀x − x₀ = (A₀𝟙)ᵀx − x₀ = −x₀        （A₀ 对称，A₀𝟙 = 0）
而 𝟙ᵀb = 0
⇒ x₀ = 0
于是 A'x = A₀x − x₀e₀ = A₀x = b
```

即 **x 精确满足原方程，且自动落在 `p₀ = 0` 的规范上**。这不是罚函数、不是近似，
没有引入任何误差。（`e₀` 是第 0 个标准基向量。）

### 8c. 无需选主元（顺带得到的稳定性论证）

- `λ_xy < 0` 的列：`|d_0| = |λ_xy| + 1 > 1`，内部 `|d_k| = |λ_xy| + 2 > 2` → 严格对角占优。
- `λ_xy = 0` 的列：加定规后 `|d_0| = 2 > 1`，其余行弱占优且矩阵不可约。

→ **不可约对角占优** ⇒ 非奇异，且 Thomas 无需选主元数值稳定（`w_k` 恒不为 0）。

## 9. cuFFT 的布局与归一化 —— 两个静默陷阱

### 9a. 轴序

cuFFT 是 row-major，`n[]` 的**最后一维最快**。我们 x 最快 ⇒ `n = {Ny, Nx}`
（与已经删除的 `cufftPlan3d(Nz, Ny, Nx)` 同一套轴序约定）：

```cpp
int n[2] = { Ny, Nx };
cufftPlanMany(&plan_xy, /*rank=*/2, n,
              n, /*istride=*/1, /*idist=*/Nx*Ny,
              n, /*ostride=*/1, /*odist=*/Nx*Ny,
              CUFFT_Z2Z, /*batch=*/Nz);
```

z-slab 在 `IDX` 布局下天然连续（`idist = Nx*Ny`），**无需任何重排**。
搞反不报错，只得到转置的场——与 `.fpd` 的 `(Nz,Ny,Nx)` 是同一类陷阱。

### 9b. 归一化

cuFFT 不归一化，forward+inverse 放大 **变换点数**：2D 批量版是 **`Nx·Ny`**
（3D 版才是 `Nx·Ny·Nz`）。

照抄 `/size` 会让 `p` 小 `Nz` 倍 → `∇·v ≠ 0`。这是从 3D 版移植到 2D 批量版时
最容易踩的坑（Phase 7-A 的 spike P2 实测：放大因子**精确等于 `Nx·Ny`**），
所以归一化因子在 `solve_pressure` 里**只出现一次**。

## 10. 复杂度与访存

| 步骤 | 复杂度 | 备注 |
|---|---|---|
| 2D 批量 FFT | `Nz · O(Nx Ny log(Nx Ny))` | 批量 Nz 个 Nx·Ny 变换 |
| Thomas | `2·Nz` 步串行，`Nx·Ny` 路并行 | 生产盒 8192 线程 × 32 步 |
| `tri_w` | 一次性 `Nx·Ny·Nz` doubles = 2 MB | 与右端无关 |

`collapse(2)` 开在 `(i,j)`，内层 k 串行。固定 k 时相邻线程访问相邻地址
（`IDX` 的 x 最快）→ **访存完全合并**。

## 14. 壁面速度边界条件、噪声与判据（Phase 7-B）

第 5 节解出了泊松算子要解的方程，但**求解器本身不产生边界条件** —— 边界条件是
主循环（`Stokes.cpp`）施加的。这一节把「壁面 BC 到底怎么落地」写全。

### 14.1 切向无滑移的壁面通量展开式

壁面上没有 `vx`/`vy` 自由度（它们在整数 z 层，壁面在半格处 `z = ∓1/2`）。标准 MAC ghost：

```
vx[-1] = -vx[0]        vx[Nz] = -vx[Nz-1]        （vy 同理）
vz[i,j,-1] = vz[i,j,Nz-1] = 0                    （法向，恒 0）
```

代入 `Π_zx` 的既有表达式（`Stokes.cpp` 里 `pi_ny` 那一段）即得：

| 项 | 壁面棱边（逻辑 `k=-1`）上的值 |
|---|---|
| 对流 `vsx_z = (vx[k] + vx[k+1])/2` | `(-vx[0] + vx[0])/2 = 0` |
| 对流 `vsz_x = (vz[ip,k] + vz[i,k])/2` | `0`（`vz[-1] = 0`） |
| 粘性 `vx[k+1] - vx[k]` | `vx[0] - (-vx[0]) = 2·vx[0]` |

上壁棱边对称地给出 `vx[Nz] - vx[Nz-1] = -2·vx[Nz-1]`。
**两个对流因子同时为 0 是物理正确的**（壁面不输运动量），`±2vx` 正是单侧导数除以半格。

代码把这一步代数代入显式写在独立壁面 kernel 中：

```
Π_zx(bottom) = −2η_zx(bottom)·vx[0]       − Σ_zx(bottom)
Π_zx(top)    = +2η_zx(top)·vx[Nz−1]       − Σ_zx(top)
Π_yz(bottom) = −2η_yz(bottom)·vy[0]       − Σ_yz(bottom)
Π_yz(top)    = +2η_yz(top)·vy[Nz−1]       − Σ_yz(top)
```

于是 `Stokes.cpp` §2 的三个 kernel 分别覆盖体心与 XY 棱、内部 YZ/ZX 棱、两片壁面。
W3 检查组合后的离散 Poiseuille 算子，W3b 直接检查上述四条通量公式。

### 14.2 棱边数组为什么必须多一层

`Π_yz`/`Π_zx` 与 `etaYZ`/`etaZX` 位于 z 面层，逻辑下标 `k` 表示 `z = k+1/2`。
壁面在 `z = ∓1/2` 即逻辑 `k = -1` 与 `k = Nz-1`：

- `k = Nz-1`（上壁）**已经在数组里**（`IDX` 对 `k ∈ [0,Nz)` 有定义）
- `k = -1`（下壁）**在数组之外**

而这两层承载的 `vx` 完全不同（一个是 `-vx[0]`，一个是 `-vx[Nz-1]`）。
若沿用 Nz 层布局，`k=-1` 会周期回绕到 `Nz-1`，**两者撞同一个槽位** ⇒ 静默用错壁面剪切。

因此棱边数组开 **Nz+1 层**，下壁落在槽位 0：

```
edge_idx(i,j,k) = i + j·Nx + (k+1)·Nx·Ny        （k ∈ [-1, Nz-1]）
```

> ⚠️ **关键设计**：逻辑 `k` 的物理含义与存储映射**解耦**。于是所有写 `k`、`k-1` 的
> 物理代码语义一字不变 —— 这正是避开「整体重编号」那类静默漂移的核心。
> 映射只在本节这一处出现（代码里是 `Wall.h` 的 `wz_edge_idx`）。
>
> ⚠️ 另一面：**越界不再被兜住**。原来的周期臂有 `%Nz` 会静默吸收任何越界 `k`，
> 现在 `edge_idx` 完全没有回绕 —— 调用方传 `k ∉ [-1, Nz-1]` 就是一次无诊断的
> 越界写。这份安全是**调用方的前置条件**，不是访问器的性质
> （`acc routine seq` 里做不了运行时检查）。

### 14.3 【推导】壁面剪切噪声必须 ×√2

这是做错了不会报错、只会让壁面附近 kT 系统性偏低的一项。

记 `G` = 「速度 → 棱边应变率」，`D` = 「棱边应力 → 面心力」（代码里就是 `pi[k] - pi[k-1]`）。

- 内部棱边的 `G` 行是 `[-1, +1]`
- **壁面棱边的 `G` 行是 `[+2]`**（由 §14.1 的 ghost）
- 而有限体积散度在壁面棱边的系数是 **1**（不是 2）：`(∇·Π)_x[0] ⊃ Π[+½] - Π[-½]`

于是

```
D = -Gᵀ·W ,   W = diag(w),   w_内部 = 1,   w_壁面 = 1/2
```

`w_壁面 = 1/2` 的物理含义：壁面棱边只占**半个控制体**（`z ∈ [-1/2, 0]`）。
耗散算子

```
A = D·diag(η)·G = -Gᵀ·diag(η·w)·G          ← 对称、半负定
```

噪声力协方差（噪声幅度 ∝ √(η·γ)）

```
⟨ffᵀ⟩ = D·diag(η·γ·2kT/dt)·Dᵀ = (2kT/dt)·Gᵀ·diag(η·γ·w²)·G
```

离散涨落耗散要求它等于 `-(2kT/dt)·A`，即 `γ·w² = w` ⇒ **`γ = 1/w`** ⇒ **壁面棱边 `γ = 2`**。

**独立佐证**：涨落应力的方差 `∝ 1/控制体体积`。壁面棱边控制体是内部的一半
⇒ 方差 ×2 ⇒ 幅度 ×√2。两条互不依赖的论证给同一个数。

**范围**：只有 `EDGE_YZ` / `EDGE_ZX` 的两个壁面平面需要它。
`Π_zz`（体心）的壁面行是 `[+1 @ vz[0]]`（因 `vz[-1]=0`），散度端系数也是 1
⇒ `w = 1`，**不需要修正**；`Π_xy` 与 `Π_xx/Π_yy` 全在完整控制体上，同样不需要。

> 内部 kernel 固定取 γ=1；壁面 kernel 直接取 `noise_gamma1 ? 1 : 2`，并按
> `sqrt(eta * wall_gamma)` 进入幅度。`cfg.noise_gamma1` 可以把 γ 强制成 1 跑对照 —— 判据 W5 用它证明
> **√2 是被数据选中的，不是被假设的**（见 §14.7）。

### 14.4 【推导】壁面下的能量均分目标值

3A/3B 的目标值建立在 Fourier 模式基上；z 不周期后模式基不再是纯 Fourier。
改用**自由度计数**，与模式基无关：

```
速度自由度   n_v = Nx·Ny·Nz (vx) + Nx·Ny·Nz (vy) + Nx·Ny·(Nz−1) (vz 自由面)
                 = Nx·Ny·(3Nz − 1)
散度约束的秩     = Nx·Ny·Nz − 1        （常压力在左零空间，1ᵀD = 0）
dim = n_v − rank(D) = n_v − size + 1 = Nx·Ny·(2Nz − 1) + 1
```

无散子空间上平稳协方差是 `kT·P`（`P` = 正交投影），故 `⟨Σ_r |v|²⟩ = kT · dim`。
当 x/y 也周期时同一式退化为 `2·size + 1` —— 与已删除的 3A/3B 的约定自洽，
**这是对这条公式的交叉检验**（也是它唯一能做的自检，因为周期路径已经不在代码里了）。

> `dim` 由 `w5_wall_equipart` 按 `Nx·Ny·(2Nz−1)+1` 使用；修改自由度布局时必须同步。

> `D = -GᵀW` 在壁面下依然精确成立（壁面 z 面同时被 `grad` 和 `div` 排除），
> 所以 `P` 仍是正交投影，上式成立。

### 14.5 【推导】z 向动量收支恒等式

把 `vz` 的更新式对所有自由面与所有 `(i,j)` 求和。xy 剪切项在周期方向望远镜到 0，
z 向项在 `k = 0…Nz−2` 上望远镜：

```
Σ_{ij,k自由} (vz^{n+1} − vz^n)/dt = F_z − (P̄_{Nz−1} − P̄_0) − (Z̄_{Nz−1} − Z̄_0)

P̄_k = Σ_ij p[i,j,k]      Z̄_k = Σ_ij Π_zz[i,j,k]      F_z = Σ_{自由面} fz
```

**每一步都精确成立的代数恒等式**（不需要稳态），且一次性检验四件事：
`fz` 在壁面被截断为 0、`vz` 在两壁被钉死、压力梯度、`Π_zz`。

> 稳态时左边为 0，右边就是「壁面通过静压 + 法向应力支撑粒子重量」。

### 14.6 平面 Poiseuille 的精确离散闭式

均匀体力 `fx = g`、`η ≡ 1`、无噪声、稳态。此时 `vx` 与 x,y 无关 ⇒ 对流恒 0、
`div v = 0` ⇒ `p ≡ 0`，纯粘性-外力平衡。离散方程：

```
内部 k      vx[k+1] - 2vx[k] + vx[k-1] = -g/η
壁面 k=0    vx[1]   - 3vx[0]           = -g/η      （由 ghost vx[-1] = -vx[0]）
```

解得

```
vx[k] = (g/2η)·[ (Nz²+1)/4 − (k − (Nz−1)/2)² ]
```

> ⚠️ 判据必须用**这个离散闭式**，不能用连续抛物线 `(g/2)(Nz²/4 − z²)`：
> 后者带 `O(1/Nz²)` 的假偏差（`Nz=16` 时 0.39%），足以让人误判 ghost 写错了。
> 两者的相对差恰为 `1/(2Nz²)`（实测 3.906e-3 @ Nz=16，理论 1.953e-3 的同量级）。

## 15. 粒子-壁面排斥势（Phase 6）

### 15.1 为什么必须有

无滑移壁面的**速度**边界是 §14 的内容，它管的是流场。但粒子是另一回事：
`Velocity.cpp` 的 z 向**故意不 clamp**（clamp 会把穿墙变成一条看起来正常的轨迹），
`main.cpp` 的 `check_wall_bounds` 一旦发现越界就写盘并中止（rc=3）。
于是**任何真正的重力沉降都会以中止收场** —— 粒子必然堆到底壁。

§14.5 的 z 向动量收支恒等式在稳态下写的就是这件事：
壁面通过静压与法向应力**托住**粒子的重量。速度边界条件本身不产生这个托举力，
它只负责让流体不能穿透壁面。粒子停在哪个高度，由**粒子**受的力决定。

### 15.2 自变量是「表面间隙」，不是「中心距」

```
h_bottom = (z + 1/2) - a          a = radius（同一个粒子半径）
h_top    = (Nz - 1/2 - z) - a
```

选间隙而不是中心距的理由是**参数独立性**：改 `radius` 时平衡间隙不变；
用中心距的话，改 `radius` 会让粒子静默地越陷越深（甚至把表面压进壁里）。

势函数族**逐字复用**粒子间势的 `pair_force_over_r`（在 h 坐标上求值），
所以 §12 里 J1 那条「力 = −dU/dr 的四阶数值微分」判据**自动覆盖**本模块的公式，
不需要为壁面再写一份势。新增的只有几何装配。

### 15.3 ⚠️ 这是模型，不是推导

本模块**不是**从 FPD 第一性原理推出的壁面自由能（那需要把粒子-壁面的相互作用
对壁面半空间做积分，且随势族不同有不同闭式）。它是**为了让粒子停在一个可控间隙上**
而选的一个排斥势，参数（`wall_sigma` / `wall_eps`）由使用者按目标平衡间隙反解。

判据管的是「实现对不对」，不管「这个模型是不是某个真实胶体壁面势」——
与本项目对 `Potential.h` 的一贯立场一致。

### 15.4 前置条件 `h > 0` 是调用方的责任

`pair_force_over_r(h²)` 对负的 h 会给出**符号反向**的力（h < 0 时 h² 仍为正），
把粒子往壁里推 —— 一条无诊断的错物理路径。所以：

- `wall_force_z` **不兜底、不 clamp**（与 `Velocity.cpp` 的「z 向从不折叠」同一立场）
- `main.cpp` 的 `check_wall_bounds` 在 `wallpotential != none` 时把合法区间**收紧**到
  `z ∈ [−1/2 + a, Nz − 1/2 − a]`，即 `h > 0`；越界即中止

### 15.5 平衡高度与「上壁没有平衡点」

对向下的重力 `g_z < 0`：

- **下壁有平衡点**：`F_wall(h_rest) = |g_z|` 反解出 `h_rest`，粒子中心停在
  `z_rest = −1/2 + a + h_rest`。这是沉降堆积的稳态高度。
- **上壁没有平衡点**：上壁的排斥方向朝下（远离壁面），与重力**同向**。
  两者叠加，永远托不住粒子。判据 W8e 里对此有专门断言
  （镜像位置的壁面力反对称 ⇒ 总力 `= 2·g_z`）—— 把它写成「上壁也该平衡」
  会得到一个永远 FAIL 的假判据。

### 15.6 平衡间隙处的相场截断

`stencil_point` 会按 `Loc` 在壁面处截断相场（§12 的最后几行、`LocZKind<L>`）。
粒子离壁越近，`sum_phiz < sum_phix` 越明显 —— W4 实测 `Rz = 4.0` 时
`z/x = 0.995309`（亏损 0.47%）。这**不是缺陷**，是扩散界面在硬壁前被截断的
真实后果；但它意味着贴壁粒子的 z 向有效质量/迁移率是 z 相关的。

**实践含义**：选壁面势参数时应让 `z_rest` 落在截断亏损 ≲1% 的区间
（本项目参数下约 `z_rest ≳ 4`）。`dump_config` 会把 `h_rest` 与 `z_rest`
一并打印出来，配错了能一眼看见。

### 15.8 判据的判别力（只测 PASS 的判据是哑的）

`fpd_tool --verify-forces` 用 `config.used` 在 CPU 上重算 F，与检查点里 GPU 算的 F 比。
在一个**已经停在壁面平衡高度**的检查点上（单粒子，z ≈ 4.69，壁面力 ≈ 10）：

| 传给 verify-forces 的配置 | max\|ΔF\| | 结果 |
|---|---|---|
| 与产生检查点的配置一致 | **0.000e+00** | PASS |
| `wall_eps` 减半 | **6.806e+00** | FAIL |
| `wallpotential = none` | **1.361e+01** | FAIL |

两个 FAIL 的幅度都与「壁面力 ≈ 10」自洽，而且**没有一个判据能靠"两边一起错"自洽通过**
（把 `wall_eps` 改掉时文件里的 F 是旧值、重算的 F 是新值，两者不会一起漂）。

> 同一个测试在 N=95 的**生产检查点**上（粒子还在体相、离壁 > rcut）改 `wall_eps`
> **仍然 PASS 且 ΔF = 0.000e+00** —— 这正是 W8c「体相逐位零力」在真实数据上的体现，
> 不是判据失灵。

> W8d 是力平衡判据，不是动力学判据。流体驰豫时间 `τ ≈ (L/π)²/ν` 是几万步量级；
> 把它放进 `--check-wall` 会让判据从 2 分钟变成几十分钟而**判别力不增加**
> （力平衡是动力学的必要条件，且是这里唯一可精确判的量）。
