### 一、为什么壁面是 $z = -1/2$ 与 $z = Nz - 1/2$？

根本原因在于：**计算域由 $Nz$ 个“胞元（Cell）”构成，壁面必须正好卡在第一个胞元的下底面和最后一个胞元的上顶面上。**

在 MAC 网格中，每个变量的坐标约定如下（设网格步长 $\Delta z = 1$）：

* **胞心（Cell Center，存压力 $p$）**：索引 $k$ 的物理坐标为整点 $z = k$。
因为一共有 $Nz$ 个胞元，指标为 $k = 0, 1, 2, \dots, Nz-1$：


* 第 $0$ 个胞元的中心是 $z = 0$
* 最后一个（第 $Nz-1$ 个）胞元的中心是 $z = Nz - 1$


* **$z$ 面心（$z$-face，存竖直速度 $v_z$）**：索引 $k$ 的物理坐标定义在胞元的**上表面**，即半整点：

$$z(v_z[k]) = k + \frac{1}{2}$$




现在我们来看整个流体域的上下几何边界：

```text
               z 坐标                      变量与含义
────────────────────────────────────────────────────────────────
上边界 (Top)   z = Nz - 1/2  ─────── vz[Nz-1] (第 Nz-1 胞元的顶面，即上壁面)
               z = Nz - 1             p[Nz-1]  (第 Nz-1 胞元的中心)
               z = Nz - 3/2  ─────── vz[Nz-2] (内部流体面)
                  ...                  ...
               z = 1/2       ─────── vz[0]    (第 0 胞元的顶面 / 第 1 胞元的底面)
               z = 0                  p[0]     (第 0 胞元的中心)
下边界 (Bottom)z = -1/2      ─────── vz[-1]   (第 0 胞元的底面，即下壁面)
────────────────────────────────────────────────────────────────

```

1. **下壁面（$Bottom$）**：
第 $0$ 个胞元的底面，在中心 $z=0$ 下方半个格距处，因此物理坐标是：

$$z = 0 - \frac{1}{2} = -\frac{1}{2}$$




这个面对应的面心速度指标按公式 $k + \frac{1}{2} = -\frac{1}{2}$ 算，就是虚拟索引 $k = -1$。


2. **上壁面（$Top$）**：
总共只有 $Nz$ 个胞元，最顶部的胞元指标是 **$k = Nz - 1$**（不是 $Nz$）。
这个最顶部胞元的顶面，在其中心 $z = Nz - 1$ 上方半个格距处，因此物理坐标是：

$$z = (Nz - 1) + \frac{1}{2} = Nz - \frac{1}{2}$$




对应面心速度就是 $v_z[Nz-1]$。



* **为什么不是 $Nz + 1/2$？**
如果上边界是 $z = Nz + 1/2$，那么它对应的胞元中心就是 $z = Nz$。从 $k = 0$ 到 $k = Nz$，总共就会有 $Nz + 1$ 个胞元，而不是系统设定的 $Nz$ 个胞元。
整个计算域的高度就是顶面减底面：



$$H = \left(Nz - \frac{1}{2}\right) - \left(-\frac{1}{2}\right) = Nz$$




正好容纳 $Nz$ 个高度为 1 的网格胞。

### 二、这里的一阶导和二阶导分别是什么？

在连续体系下，泊松方程是二阶偏微分方程：


$$\nabla^2 p = \frac{\partial^2 p}{\partial x^2} + \frac{\partial^2 p}{\partial y^2} + \frac{\partial^2 p}{\partial z^2}$$

在 MAC 交错网格上，这个**二阶导数从来不是一步差分出来的**，而是严格拆成**两步一阶导数（差分）的复合**：

#### 1. 第一个一阶导：梯度算子 $G_z \approx \frac{\partial}{\partial z}$（胞心 $\to$ 面心）

作用在体心（压力 $p$）上，算出来的值落在**面心**上：


$$(G_z p)[k] = p[k+1] - p[k]$$


（即面心 $k+1/2$ 处的压力梯度，是用它两侧的胞心压力 $p[k+1]$ 和 $p[k]$ 做中心差分：$\frac{p[k+1]-p[k]}{\Delta z}$）。

#### 2. 第二个一阶导：散度算子 $D_z \approx \frac{\partial}{\partial z}$（面心 $\to$ 胞心）

作用在面心（速度 $v_z$）上，算出来的值落在**胞心**上：


$$(D_z v_z)[k] = v_z[k] - v_z[k-1]$$


（即胞心 $k$ 处的速度散度，是用包围它的上表面速度 $v_z[k]$ 减去下表面速度 $v_z[k-1]$）。

#### 3. 二阶导：两者的复合 $L_z = D_z \circ G_z \approx \frac{\partial^2}{\partial z^2}$

在域内部（远离壁面处），将梯度代入散度：


$$(L_z p)[k] = (G_z p)[k] - (G_z p)[k-1] = (p[k+1] - p[k]) - (p[k] - p[k-1]) = p[k+1] - 2p[k] + p[k-1]$$


这正是我们在胞心处看到的标准三点二阶中心差分 $[1, -2, 1]$。

### 三、什么是“所谓算子截断推导”？

在常规偏微分方程数值解法中，处理边界条件通常是：**先对微分方程套一个通用二阶差分模板，遇到超出边界的点（如 $p[-1]$），再去强行塞一个虚拟点边界条件（Ghost Point）进行消除**。

而文档中所说的“算子截断推导”，是一种**完全从物理离散算子和约束直接展开**的推导方式——**不预设任何边界差分公式，只看代数运算在边界上实际发生了什么**。

推导过程如下：

根据修正步，速度更新公式为 $v_z^{n+1} = v_z^* - \Delta t \, G_z p$。
但在物理壁面上，流体不可穿透，壁面法向速度恒为 $0$，**不需要也不能被压力修正**：

* 下壁面：$v_z[-1] = 0$

* 上壁面：$v_z[Nz-1] = 0$

* 内部自由面（$k = 0, \dots, Nz-2$）：执行正常修正


$$v_z[k] = v_z^*[k] - \Delta t (p[k+1] - p[k])$$




现在，我们直接写出第 $0$ 个胞元（紧贴下壁面）在修正步之后的离散散度：


$$(D_z v_z^{n+1})[0] = v_z^{n+1}[0] - v_z^{n+1}[-1]$$

将上面的修正公式代入：

* $v_z^{n+1}[0] = v_z^*[0] - \Delta t (p[1] - p[0])$（上表面是内部自由面，受压力梯度修正）


* $v_z^{n+1}[-1] = 0$（下表面是刚性壁面，恒等于 $0$，没有任何压力项！）



相减得到：


$$(D_z v_z^{n+1})[0] = v_z^*[0] - \Delta t (p[1] - p[0]) - 0 = v_z^*[0] - \Delta t (p[1] - p[0])$$

让它等于 $0$，即得到胞元 $k=0$ 处的压力离散方程：


$$-(p[1] - p[0]) = \frac{1}{\Delta t} (D_z v_z^*)_0$$

#### 为什么叫“算子截断”？

对比例子就能一目了然：

* **内部普通胞元（标准二阶导）**：

$$L_z p[k] = p[k+1] \mathbf{- 2} p[k] + p[k-1]$$




系数是：`[+1, -2, +1]`，主对角线是 **$-2$**。


* **边界胞元 $k=0$（截断后的二阶导）**：

$$-(p[1] - p[0]) = p[1] \mathbf{- 1} p[0]$$




系数是：`[+1, -1]`，主对角线变成了 **$-1$**，穿过下壁面的那个邻居项被硬生生地“截断”掉了。



同理，顶层胞元 $k = Nz-1$ 处，因为上表面 $v_z[Nz-1]=0$，算子被截断为 $-(p[Nz-1] - p[Nz-2])$，主对角线也是 **$-1$**。

这就是为什么三对角矩阵的对角线两端各自“少了一个 $-1$”（从 $-2$ 变成 $-1$）：
它根本不需要去假设外面的虚拟压力 $p[-1]$ 是什么，仅仅是**因为刚性壁面没有压力修正自由度，导致散度与梯度的复合链在边界处被自然截断**。这样的算子与修正步是完全数学兼容的，因此算出来的速度场散度可以在壁面处直接压到机器精度。
