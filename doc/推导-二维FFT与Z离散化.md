沿着之前推导的思路，我们将三维压力泊松方程拆开：**水平 $(x, y)$ 用 2D FFT 解耦，竖直 $z$ 方向用代数消元求解**。

---

### 第一步：从 2D FFT 到竖直方向的三对角方程组

在之前的推导中，我们在连续空间用傅里叶变换将导数变成了代数乘法，离散网格上也是同理。

三维拉普拉斯算子是水平和竖直的叠加：


$$\nabla^2 p \approx L_{xy} p + L_z p$$

1. **水平 $xy$ 已经解耦**：
对水平做 2D FFT 后，二维离散差分算子直接退化为一个纯标量本征值 $\lambda_{xy}$（由 $\cos \theta_x$ 和 $\cos \theta_y$ 组成）。


2. **竖直 $z$ 方向的二阶导展开**：
在之前的离散化中，标准内部网格点的二阶导公式是 $[1, -2, 1]$，即 $p_{k+1} - 2p_k + p_{k-1}$。
加上水平方向贡献的 $\lambda_{xy} p_k$，对每个频率 $(m, n)$，每一层 $k$ 的方程为：



$$p_{k-1} + (\lambda_{xy} - 2) p_k + p_{k+1} = \hat{b}_k$$


3. **结合边界截断（Neumann 边界）**：
在之前的推导中，壁面法向速度不修正，导致端点的二阶导少了一个 $-1$（主对角线从 $-2$ 变成 $-1$）：


* 底部 $k = 0$：对角线为 $d_0 = \lambda_{xy} - 1$

* 内部 $k = 1 \dots Nz-2$：对角线为 $d_k = \lambda_{xy} - 2$

* 顶部 $k = Nz-1$：对角线为 $d_{Nz-1} = \lambda_{xy} - 1$

* 次对角线与超对角线恒为 $1$




这就是为什么每个水平模式都对应一个 $Nz \times Nz$ 的**对称三对角线性方程组 $A x = b$**。

---

### 第二步：Thomas 算法为什么能“提前预算”（§7）

三对角方程组通常用高斯消元（即 Thomas 算法）来解，分为两步：从下往上消元，再从上往下回代。

假设已知第 $k-1$ 个未知数与第 $k$ 个未知数的关系，将其代入第 $k$ 行消除下三角，更新后的主对角线系数为 $d_k' = d_k - \frac{1}{d_{k-1}'}$。定义其倒数 $w_k = 1 / d_k'$，则有递推公式：


$$w_0 = \frac{1}{d_0}, \quad w_k = \frac{1}{d_k - w_{k-1}}$$

* **数学核心**：请看这个递推式，式子里只有 $d_k$（由 $\lambda_{xy}$ 和网格层数 $k$ 决定），**完全没有出现右端项 $b$**！


* **推导出的结论**：这意味着消元系数 $w_k$ 纯粹由网格几何和物理边界决定，在网格建好的一瞬间就固定了。因此不需要在每个时间步重复消元，只要在程序初始化时算好并存入 `tri_w`。实际计算时只剩下代入右端项 $b$ 的两趟纯线性扫描，计算量极低。



---

### 第三步：奇异列 $(0,0)$ 与纯数学定规（§8）

当模式为 $(m, n) = (0, 0)$ 时，$\lambda_{xy} = 0$。此时方程对应整个区域的水平平均竖向压力。

1. **为什么是奇异的？**
把 $\lambda_{xy} = 0$ 代入矩阵的对角线：
* 顶部和底部是 $-1$，内部是 $-2$，两边是 $1$。


* 检查任意一行，元素相加：$(-1) + 1 = 0$ 或 $1 + (-2) + 1 = 0$。


* 每行之和全为 0，说明全 1 向量 $\mathbf{1}$ 满足 $A_0 \mathbf{1} = 0$，即矩阵不可逆（行列式为 0，有无穷多解，差一个任意常数）。




2. **为什么不能清零？**
在纯周期流中可以把压力常数设为 0。但这里竖直方向有重力或颗粒沉降，$(0,0)$ 模态的 $x(k)$ 存储的是流体在各高度的**真实水压分布**，清零就会丢失压强支撑力。


3. **严格的秩一修改定规**：
既然差一个常数，我们不妨令基准点压力 $x_0 = 0$。
如何修改矩阵才能既固定 $x_0 = 0$，又绝对不破坏方程的原有关系？
令新矩阵 $A' = A_0 - e_0 e_0^T$（也就是只把 $d_0$ 从 $-1$ 改成 $-2$）。
根据相容性条件，整个流场净通量为零，右端项总和 $\mathbf{1}^T b = 0$。
我们在方程 $A' x = b$ 两侧同时求和（即左乘 $\mathbf{1}^T$）：



$$\mathbf{1}^T (A_0 x - x_0 e_0) = \mathbf{1}^T b \implies \underbrace{(\mathbf{1}^T A_0)}_{0} x - x_0 = 0 \implies x_0 = 0$$




既然 $x_0$ 严格等于 $0$，那么代回新方程：$A' x = A_0 x - x_0 e_0 = A_0 x = b$ 仍然严格成立。
**结论**：把第一行对角元减 1，既瞬间打破了矩阵的奇异性（使其严格对角占优、Thomas 算法绝对稳定），又在数学上精确锁定了唯一的物理特解 $p_0 = 0$。



---

### 第四步：由 FFT 和三对角直接导出的工程结论（§9, §10, §11）

* **归一化尺寸（§9b）**：
我们只在 $x, y$ 两个方向用了离散傅里叶变换，变换的点数是 $Nx \cdot Ny$；$z$ 方向走的是代数消元而不是 FFT。因此，做逆变换时除以的缩放因子只能是 $Nx \cdot Ny$，而不是全网格的 $Nx \cdot Ny \cdot Nz$。


* **GPU 访存合并（§10）**：
$Nx \cdot Ny$ 个方程组彼此完全独立。让 GPU 线程覆盖 $(i, j)$，内层循环沿高度 $k$ 扫描：当所有线程在同一高度 $k$ 取数时，由于内存布局中 $x$ 变化最快，相邻线程读取的恰好是相邻的连续内存地址，实现了最优的硬件级合并访存。


* **往返闭环检验（§11）**：
由于算子在代数上完全对称且相容，如果拿一个参考场 $p_{\text{ref}}$ 手写求散度梯度得到 $b$，再放进求解器反解，输出的 $p$ 必须与输入严格相同（仅相差一个固定常数），误差可以直接压到浮点截断极限（$\sim 10^{-15}$）。


这个公式推导的核心是：**对水平方向做二维离散傅里叶变换（2D DFT），利用其本征性质将水平差分算子直接替换为标量 $\lambda_{xy}$，从而把偏微分差分方程降维为竖直方向的常微分差分方程**。

详细的逐项推导过程如下：

---

### 1. 物理实空间的三维二阶差分

设三个方向的网格步长 $\Delta x = \Delta y = \Delta z = 1$。
在 MAC 网格体心 $(i, j, k)$ 处，三维拉普拉斯算子展开为三组标准的二阶中心差分之和：


$$(L p)_{i,j,k} = (L_{xy} p)_{i,j,k} + (L_z p)_{i,j,k} = b_{i,j,k}$$

将水平项 $L_{xy}$ 和竖直项 $L_z$ 分别写开：

* **竖直差分项 $L_z p$**（针对内部网格层 $k$）：



$$(L_z p)_{i,j,k} = p_{i,j,k+1} - 2p_{i,j,k} + p_{i,j,k-1}$$


* **水平差分项 $L_{xy} p$**：

$$(L_{xy} p)_{i,j,k} = (p_{i+1,j,k} - 2p_{i,j,k} + p_{i-1,j,k}) + (p_{i,j+1,k} - 2p_{i,j,k} + p_{i,j-1,k})$$



将它们组合起来，在实空间中，对于任意一个网格点 $(i, j, k)$，泊松方程是：


$$\underbrace{(p_{i+1,j,k} - 2p_{i,j,k} + p_{i-1,j,k}) + (p_{i,j+1,k} - 2p_{i,j,k} + p_{i,j-1,k})}_{(L_{xy} p)_{i,j,k}} + \underbrace{(p_{i,j,k+1} - 2p_{i,j,k} + p_{i,j,k-1})}_{(L_z p)_{i,j,k}} = b_{i,j,k}$$

---

### 2. 水平方向的 2D 离散傅里叶变换 (2D DFT)

因为 $x$ 和 $y$ 方向是周期性边界条件，我们在固定的高度 $k$ 上，对水平面 $(i, j)$ 做二维离散傅里叶变换。
定义频域模式 $(m, n)$ 下的傅里叶系数 $\hat{p}_{m,n,k}$ 为：


$$\hat{p}_{m,n,k} = \sum_{i=0}^{Nx-1} \sum_{j=0}^{Ny-1} p_{i,j,k} \, e^{-i (\theta_x i + \theta_y j)}$$


其中离散波数为 $\theta_x = \frac{2\pi m}{Nx}$，$\theta_y = \frac{2\pi n}{Ny}$。

根据离散傅里叶变换的时移性质（Index Shift Property）：

* 沿 $x$ 正向移动一格 $p_{i+1,j,k} \longleftrightarrow e^{i \theta_x} \hat{p}_{m,n,k}$
* 沿 $x$ 负向移动一格 $p_{i-1,j,k} \longleftrightarrow e^{-i \theta_x} \hat{p}_{m,n,k}$

对 $x$ 方向的差分项做傅里叶变换：


$$\mathcal{F}_{xy}\{ p_{i+1,j,k} - 2p_{i,j,k} + p_{i-1,j,k} \} = \left(e^{i \theta_x} - 2 + e^{-i \theta_x}\right) \hat{p}_{m,n,k} = 2(\cos \theta_x - 1) \hat{p}_{m,n,k}$$

同理，对 $y$ 方向差分项做傅里叶变换：


$$\mathcal{F}_{xy}\{ p_{i,j+1,k} - 2p_{i,j,k} + p_{i,j-1,k} \} = \left(e^{i \theta_y} - 2 + e^{-i \theta_y}\right) \hat{p}_{m,n,k} = 2(\cos \theta_y - 1) \hat{p}_{m,n,k}$$

把它们相加，**整个水平算子 $L_{xy}$ 在频域中直接退化为一个标量乘法因子**：


$$\mathcal{F}_{xy}\{ L_{xy} p \} = \underbrace{\left[ 2(\cos \theta_x - 1) + 2(\cos \theta_y - 1) \right]}_{\text{记为 } \lambda_{xy}} \hat{p}_{m,n,k} = \lambda_{xy} \hat{p}_{m,n,k}$$

---

### 3. 方程两端同时作用 2D DFT

现在对完整的实空间差分方程两边同时做关于水平方向 $(x, y)$ 的傅里叶变换：


$$\mathcal{F}_{xy}\{ (L_{xy} p)_{i,j,k} + (L_z p)_{i,j,k} \} = \mathcal{F}_{xy}\{ b_{i,j,k} \}$$

注意 $L_z$ 只涉及 $k$ 维度的变化，与水平索引 $i, j$ 互相独立，傅里叶变换对 $k$ 来说是线性算子：


$$\mathcal{F}_{xy}\{ p_{i,j,k+1} - 2p_{i,j,k} + p_{i,j,k-1} \} = \hat{p}_{m,n,k+1} - 2\hat{p}_{m,n,k} + \hat{p}_{m,n,k-1}$$

代入水平项的变换结果：


$$\lambda_{xy} \hat{p}_{m,n,k} + \left( \hat{p}_{m,n,k+1} - 2\hat{p}_{m,n,k} + \hat{p}_{m,n,k-1} \right) = \hat{b}_{m,n,k}$$

---

### 4. 整理同类项

在固定的某个水平频率 $(m, n)$ 下，省略下标 $m, n$，简记频域变量 $\hat{p}_{m,n,k}$ 为 $p_k$，右端频域项为 $\hat{b}_k$：


$$\lambda_{xy} p_k + p_{k+1} - 2p_k + p_{k-1} = \hat{b}_k$$

将 $p_k$ 的系数合并：


$$p_{k-1} + (\lambda_{xy} - 2) p_k + p_{k+1} = \hat{b}_k$$

由此完成推导：

* $p_{k-1}$ 和 $p_{k+1}$ 来自 $z$ 方向二阶中心差分的非对角项，系数为 $1$。


* 内部层对角线系数 $(\lambda_{xy} - 2)$ 则是由水平拉普拉斯的本征值贡献 $\lambda_{xy}$，加上竖直拉普拉斯本身的中心项 $-2$ 合并而成。
